# Hackathon – kontext

Arbetsyta för Meta Global AI Developer Hackathon (26/10–5/11 2026).
Här samlas idé, backlog, kunskap och kontext som Muse, agent och model Bot läser innan de jobbar.

- `ide.md` – vad vi bygger och varför
- `backlog.md` – att göra, prioriterat
- `kontext/` – hackathonet, arbetssätt, teknik
- `kunskap/` – godkända kunskapsanteckningar (domän, bytecode, data)
- `beslut/` – beslutslogg, en rad per beslut
